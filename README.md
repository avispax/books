# books

蔵書の一覧。正本は [booklist.md](booklist.md)。集計は [集計.md](集計.md)（Obsidian の Dataview で表示する）。

## 1. 使い方

1. 本屋で「持ってたっけ」と思ったら、`booklist.md` をページ内検索する。ISBN で探すときは、本の裏の 13 桁から先頭の `978` と末尾の 1 桁を除いた 9 桁で検索する。
2. 点数・区分・タグは、`booklist.md` の各行の末尾に書く。

## 2. 書き方

1. **点数**: `[score:: 0〜100]`
2. **ジャンル（本屋のフロア/棚）**: 階層タグで付ける。1 冊に複数付けてもいい。増やしてもいい
   1. 技術: `#技術/プログラミング` `#技術/設計` `#技術/テスト` `#技術/データベース` `#技術/クラウド` `#技術/インフラ` `#技術/AI` `#技術/セキュリティ` `#技術/Web`（HTTP・REST・GraphQL・gRPC・Web API） `#技術/フロントエンド`（HTML・CSS・React・Vue） `#技術/コンピュータ`（CPU・OS・アルゴリズムなどの基礎） `#技術/モバイル`（iOS・Android） `#技術/ツール`（エディタ・Git・シェル・Excel）
   2. スポーツ: `#スポーツ`、`#スポーツ/サッカー`
   3. ビジネス: `#ビジネス/経営` `#ビジネス/マーケティング` `#ビジネス/営業`
   4. デザイン: `#デザイン/UI`（UI・UX・デザインシステム） `#デザイン/グラフィック`（レイアウト・配色・フォント・資料） `#デザイン/プロダクト`（もの・ゲームのデザイン）
   5. マネジメント: `#マネジメント/チーム`（チームづくり・ファシリテーション・リーダーシップ） `#マネジメント/組織`（組織論・組織文化） `#マネジメント/プロジェクト`（PMBOK・WBS・見積もり）。細かく分けていない本は `#マネジメント` のまま
   6. その他: `#その他`（どこにも当てはまらない本） `#法律` `#労務`（給与計算・年末調整・社会保険） `#健康` `#趣味` `#小説` `#資格`（試験対策） `#ゲーム`（ゲーム開発・ゲームデザイン・攻略本・ボードゲーム） `#学び方` `#文章` `#仕事術` `#プロダクト` `#キャリア` `#教養` `#英語` `#金融`
3. **横断の観点**: 棚とは別の独立したタグ。`#アジャイル`（チーム・プロジェクト・テストなど、どの棚の本にも付く）
4. **言語**: 棚とは別の独立したタグ。`#Go` `#Python` `#Rust` `#TypeScript` `#JavaScript` `#Java` `#CSharp` `#Cpp` `#Ruby` `#Kotlin` `#Swift` `#Haskell` `#PHP` `#Scala` `#Elixir` `#Dart` `#C`（タグに `#` と `+` は使えないので、C# は `#CSharp`、C++ は `#Cpp`）
5. **形態**: `#同人誌`、`#漫画`、`#雑誌`（Software Design・I/O・Interface・WEB+DB PRESS、サッカー誌など）。ジャンルとは別に付ける（Go の同人誌なら `#同人誌 #技術/プログラミング #Go`）
6. **100 冊**: 新人に勧める 100 冊は `#100冊`。読み方で `#100冊/そのまま` `#100冊/章だけ` `#100冊/共通言語`（周りが読んでいるので目を通す）に分ける。未決は `#100冊候補`
7. **その他のタグ**: 自由に付ける

階層タグは、親で検索すると子も含めて出る（`tag:#技術` で技術書すべて）。普通の検索なら、「サッカー」「Go」だけでも探せる。
