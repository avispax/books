# books

蔵書の一覧。正本は [booklist.md](booklist.md)。集計は [集計.md](集計.md)（Obsidian の Dataview で表示する）。

## 1. 使い方

1. 本屋で「持ってたっけ」と思ったら、`booklist.md` をページ内検索する。ISBN で探すときは、本の裏の 13 桁から先頭の `978` と末尾の 1 桁を除いた 9 桁で検索する。
2. 点数・区分・タグは、`booklist.md` の各行の末尾に書く。

## 2. 書き方

1. **点数**: `[score:: 0〜100]`
2. **ジャンル（本屋のフロア/棚）**: 階層タグで付ける。1 冊に複数付けてもいい。増やしてもいい
   1. 技術: `#技術/プログラミング` `#技術/設計` `#技術/テスト` `#技術/データベース` `#技術/クラウド` `#技術/インフラ` `#技術/AI` `#技術/セキュリティ` `#技術/Web`（HTTP・REST・GraphQL・gRPC・Web API） `#技術/フロントエンド`（HTML・CSS・React・Vue）
   2. スポーツ: `#スポーツ`、`#スポーツ/サッカー`
   3. その他: `#学び方` `#文章` `#仕事術` `#マネジメント` `#プロダクト` `#キャリア` `#教養` `#英語` `#金融`
3. **言語**: 棚とは別の独立したタグ。`#Go` `#Python` `#Rust` `#TypeScript` `#JavaScript` `#Java` `#CSharp` `#Cpp` `#Ruby` `#Kotlin` `#Swift` `#Haskell` `#PHP` `#Scala` `#Elixir` `#Dart`（タグに `#` と `+` は使えないので、C# は `#CSharp`、C++ は `#Cpp`）
4. **形態**: `#同人誌`、`#漫画`。ジャンルとは別に付ける（Go の同人誌なら `#同人誌 #技術/プログラミング #Go`）
5. **その他のタグ**: `#古典`、`#100冊候補` など自由に付ける

階層タグは、親で検索すると子も含めて出る（`tag:#技術` で技術書すべて）。普通の検索なら、「サッカー」「Go」だけでも探せる。
