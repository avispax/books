# books

蔵書の一覧。正本は [booklist.md](booklist.md)。集計は [集計.md](集計.md)（Obsidian の Dataview で表示する）。

## 1. 使い方

1. 本屋で「持ってたっけ」と思ったら、`booklist.md` をページ内検索する。ISBN で探すときは、本の裏の 13 桁から先頭の `978` と末尾の 1 桁を除いた 9 桁で検索する。
2. 点数・区分・タグは、`booklist.md` の各行の末尾に書く。

## 2. 書き方

1. **点数**: `[score:: 0〜100]`
2. **ジャンル（本屋の棚）**: `#学び方` `#文章` `#仕事術` `#マネジメント` `#プロダクト` `#設計` `#プログラミング` `#テスト` `#キャリア` `#教養`。1 冊に複数付けてもいい。増やしてもいい
3. **趣味・実用のジャンル**: `#スポーツ`（サッカーは `#スポーツ/サッカー`）、`#英語`、`#金融`
4. **その他のタグ**: `#古典`、`#100冊候補` など自由に付ける

Obsidian では、タグをクリックするか、タグ検索（`tag:#設計`）で一覧がすぐ出る。`tag:#スポーツ` で検索すると、`#スポーツ/サッカー` も含めて出る。
